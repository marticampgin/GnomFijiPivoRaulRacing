# Menu Icons

The following SVG files are unmodified assets from the official
[Lucide 0.468.0 release](https://github.com/lucide-icons/lucide/releases/tag/0.468.0):

`gamepad-2`, `keyboard`, `gauge`, `zap`, `route`, `users`, `bot`, `settings-2`,
`chevron-left`, `chevron-right`, `arrow-left`, `arrow-right`, `plus`, `flag`,
`circle-dot`.

Source URL pattern:
`https://raw.githubusercontent.com/lucide-icons/lucide/0.468.0/icons/<name>.svg`

The original license for this pinned release is in `LICENSE-lucide-0.468.0`.
The pre-existing `LICENSE` and other icon files are unchanged. Lucide uses the
ISC license, with Feather-derived portions credited under MIT.

The files retain their original 24 x 24 view box and `stroke="currentColor"`.
`circle-dot` is the handling-style fallback because this pinned release has no
`steering-wheel.svg`.
