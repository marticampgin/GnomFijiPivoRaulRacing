# Статус поставки

Дата: 26 сентября 2026. Эта запись отличает готовые локальные материалы от удалённой публикации и будущей реализации.

## Подготовлено локально

- Игровой дизайн по презентации и интервью, архитектура с источниками, roadmap с критериями перехода.
- OpenSpec `design-gnom-fiji-racing`: proposal, design, четыре capability-спецификации и tasks. Строгая валидация прошла.
- Начальная основа Godot 4.7.2, GDScript, Compatibility, Web export preset и логические действия клавиатуры/геймпада.
- Десять SVG-листов: восемь основных экранов, схема архитектуры и ключевые состояния интерфейса; PNG-превью и галерея. Игровое окружение и машина являются сгенерированным концепт-артом, не скриншотами работающего Godot-прототипа.

## Проверено

Официальная portable-сборка `4.7.2.stable.official.ed1daf0bf` выполнила headless import и запуск начальной сцены на два кадра: код 0, ошибок нет. Проверка не подтверждает Web export, производительность, физику или сетевую гонку; эти системы ещё не реализованы.

SVG отрендерены и визуально проверены. Playwright подтвердил отсутствие выхода текста за холст на всех десяти листах, загрузку изображений галереи и отсутствие горизонтального переполнения галереи при 390 px. Это не тест мобильного игрового интерфейса. Демонстрационные цены, рейтинг и характеристики не являются утверждёнными настройками игры. Итоговый список файлов и проверка текста находятся в `design/README.md`.

## Figma

Исходная презентация прочитана через Figma MCP в ходе интервью. На этапе поставки MCP исчез из доступных инструментов; повторная проверка каталога сообщила `installed: false`. Публикация новых макетов в Figma **не выполнена**. Наличие локальных SVG не является подтверждением созданного Figma-файла.

После восстановления Figma MCP: прочитать действующие навыки Figma, создать отдельный Design-файл в согласованной команде, перенести экраны и схему, проверить текстовые слои/изображения/границы, сохранить ссылку в этом документе. Исходная презентация не изменялась.

## GitHub

Цель: [marticampgin/GnomFijiPivoRaulRacing](https://github.com/marticampgin/GnomFijiPivoRaulRacing). Репозиторий существует и по последней проверке пустой. В локальном Git настроен `origin` на этот URL, создан initial commit в ветке `main` с документами, макетами и основой Godot.

GitHub connector сообщает `push: false` для подключённой учётной записи `mintloyd-blip`. Локальный `gh` сообщает недействительный токен аккаунта `mintloyd`. Удалённая публикация **не выполнена**; для неё требуется действующее подключение с правом записи. Секреты в проект не записывались.

После восстановления доступа: снова проверить удалённую историю, затем отправить подготовленный commit без force push. Если в репозитории уже появились изменения, сначала интегрировать их. Файлы прежней настройки `.codex/` и `.gemini/` не включаются в initial commit.
