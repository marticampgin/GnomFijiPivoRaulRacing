# Статус поставки

Дата: 26 сентября 2026. Эта запись отличает готовые локальные материалы от удалённой публикации и будущей реализации.

## Подготовлено локально

- Игровой дизайн по презентации и интервью, архитектура с источниками, roadmap с критериями перехода.
- OpenSpec `design-gnom-fiji-racing`: proposal, design, четыре capability-спецификации и tasks. Строгая валидация прошла.
- Начальная основа Godot 4.7.2, GDScript, Compatibility, Web export preset и логические действия клавиатуры/геймпада.
- Десять SVG-листов: восемь основных экранов, схема архитектуры и ключевые состояния интерфейса; PNG-превью и галерея. Игровое окружение и машина являются сгенерированным концепт-артом, не скриншотами работающего Godot-прототипа.

## Проверено

Официальная portable-сборка `4.7.2.stable.official.ed1daf0bf` выполнила headless import и запуск начальной сцены на два кадра: код 0, ошибок нет. Проверка не подтверждает Web export, производительность, физику или сетевую гонку; эти системы ещё не реализованы.

SVG отрендерены и визуально проверены. Playwright подтвердил отсутствие выхода текста за холст на всех десяти листах, загрузку изображений галереи и отсутствие горизонтального переполнения галереи при 390 px. Это не тест мобильного игрового интерфейса. Демонстрационные цены, рейтинг и характеристики не являются утверждёнными настройками игры. Итоговый список файлов и проверка текста находятся в `design/README.md`.

## Figma

Публикация **выполнена** через Figma MCP: [макеты и архитектура в отдельном Design-файле](https://www.figma.com/design/OejURNEY5ZRhWWOBicFNYP?node-id=0-1). Исходная презентация не изменялась. В файле десять листов с редактируемой векторной графикой, восемью растровыми изображениями и 505 нативными редактируемыми текстовыми слоями. Все листы успешно отрендерены; контактный лист, границы текста и HUD визуально проверены.

В Figma используется Arimo Regular/Bold вместо недоступного Arial. Три символа стрелки вверх-вправо заменены векторными иконками Lucide ArrowUpRight, чтобы исключить цветной emoji-fallback. Исходные SVG с Arial не изменены. Ссылки на каждый экран находятся в [описании макетов](../design/README.md). Это статические десктопные макеты, не интерактивный прототип, не работающая игра и не библиотека production-компонентов.

## GitHub

Репозиторий: [marticampgin/GnomFijiPivoRaulRacing](https://github.com/marticampgin/GnomFijiPivoRaulRacing). Initial commit `20c55f8` с документами, макетами и основой Godot опубликован в ветке `main`; удалённый SHA проверен после push. Локальный `origin` настроен на этот репозиторий.

Доступ к Figma и GitHub восстановлен; препятствий для публикации больше нет. Секреты в проект не записывались. Файлы прежней настройки `.codex/` и `.gemini/` не включены в initial commit.

## Следующий этап

Макеты приняты пользователем 2026-09-26; запись проверки с ID листов находится в `design/figma-publication.json`. Архитектура и план уточнены: Google-вход, local/test вход без Google OAuth, граница PostgreSQL и методика испытаний Linux ARM64 на 4/8 ядрах. Это проектные решения: ни авторизация, ни ARM-нагрузочный тест в текущей поставке не реализованы. Принятые Figma-листы остаются визуальным baseline; подробные auth-контракты описаны в документах, а не добавлены в эти статические экраны.

Опубликованный дизайн готов к техническому прототипу через `/opsx:apply`. Первым проверяется связка браузер + сервер, дрифт и минимальная трасса; полный перечень будущих работ сохранён в OpenSpec tasks.
