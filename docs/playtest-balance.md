# Баланс игрового теста

Версия симуляции: `prototype-v9`, сетевой протокол 6, 27 сентября 2026.
Это воспроизводимый baseline для плейтеста, не окончательный соревновательный
баланс и не числовые значения из макетов. Четыре профиля сборок не изменены.
Таблица дополняется по мере реализации новых механик.

## Осколки и приёмы v9

Источники: `game/items/item_catalog.gd`, `game/race/race_techniques.gd`,
`game/vehicle/racing_vehicle.gd`. Версии SHARD/DRIFT/techniques balance: 1.

| Параметр | Значение |
| --- | --- |
| Запас осколков | 0–20, только в текущей гонке |
| Бонус максимальной скорости | +0,5% за осколок, максимум +10% |
| Потеря при оружии/сильном контакте | 25% запаса, округление вверх |
| Порог сильного контакта | 12 единиц контактного урона |
| Разброс | Половина потерянного, округление вниз, доступен всем |
| Жизнь разброса / задержка подбора | 8 с / 0,5 с |
| Восстановление дорожного осколка | 5 с |
| Стартовое окно | Последние 0,65–0,15 с отсчёта |
| Стартовый boost | 1 с; ошибочный тайминг без штрафа |
| Поток: дистанция / боковое смещение / высота | 3–18 м / до 2,4 м / до 2,2 м |
| Поток: минимальная скорость обоих | 8 м/с, оба на поверхности |
| Поток: совпадение направления и вертикали | dot ≥ 0,9 |
| Поток: накопление / boost / cooldown | 1,2 с / 1 с / 3 с |
| Три порога заряда дрифта | 0,25 / 0,60 / 1,00 |
| Длительность boost дрифта | 1,1 / 1,5 / 2 с |

Для стартового бонуса нужно нажать газ в окне и удержать до старта. Боты проходят
тот же расчёт. Смена цели потока обнуляет накопление; поток не даёт неуязвимости.
Ускорения продлевают общий таймер до максимума текущего и нового, не суммируются
и не отнимают управление. Все четыре стиля могут получить три уровня дрифта.
Осколки меняют только предел скорости, не ускорение/лечение/мгновенную скорость.
Лёгкий контакт и повторные burn ticks запас не отнимают; разрушение обнуляет его.
Пауза останавливает таймеры, новый заезд очищает запас и состояние приёмов.

## Задний ход

Источник: `game/vehicle/racing_vehicle.gd`.

| Параметр | Значение |
| --- | --- |
| Предел тяги назад | 8 м/с (28,8 км/ч) |
| Ускорение назад | 10 м/с² × сила тормоза |
| Торможение противоположной педалью | 34 м/с² × сила педали + 1,2 м/с² |
| Снижение внешнего импульса сверх предела | 4 м/с² |
| Порог индикатора R | Продольная скорость < −0,1 м/с |

Тормоз сначала доводит скорость до нуля, задний ход начинается на следующем
физическом такте при удержании. Газ сначала останавливает движение назад.
Две педали вместе тормозят; boost не разгоняет назад и не преодолевает тормоз.
Внешний импульс не обрезается мгновенно до лимита. `BLOCKED` отдельно выключает
управление и удерживает остановку на отсчёте, финише и при недоступном вводе;
сетевой `NEUTRAL` не содержит нажатого тормоза или внутреннего флага блокировки.

## Боты

Источник: `game/ai/racing_bot_driver.gd`. Профиль выбирается до локального
заезда и сохраняется при повторе; сетевой полигон использует `normal`.

| Параметр решения | Лёгкие | Обычные | Сложные |
| --- | --- | --- | --- |
| Целевая скорость прямой, от базы 22–24 м/с | ×0,83 | ×1 | ×1,10 |
| Коэффициент оценки скорости поворота | 0,65 | 0,80 | 0,85 |
| Интервал коррекции команды | 0,16 с | Каждый такт | Каждый такт |
| Амплитуда ошибки направления | 0,07 рад | 0 | 0 |
| Интервал решения о предмете | 240 тактов | 120 тактов | 45 тактов |

Это цели управления педалями, не множители реальной максимальной скорости
или ускорения машины. Сложные боты бережнее используют ремонт, не обновляют
действующий эффект и ждут цели впереди для направленного оружия. Пространственная
проверка цели не является обещанием попадания. Все пользуются общей физикой,
прочностью и таблицей предметов; отдельный teleport за застревание удалён.
Общее безопасное восстановление вне трассы остаётся для всех участников.

## Общие подарки

Источники: `game/items/race_items.gd`, `game/items/item_catalog.gd`;
`LOOT_VERSION = 1`.

| Параметр | Значение |
| --- | --- |
| Восстановление подарка | 2 с времени симуляции |
| Радиус подбора | 2 м |
| Максимум подборов одному участнику за такт | 1 |
| Вклад нормализованного места | 65% |
| Вклад отрыва от лидера | 35%, насыщение при 150 м |

Получатель: ближайшая подходящая машина, при равенстве расстояний сначала
меньший grid slot, затем ID. Тип участника не учитывается. Полные слоты не
потребляют подарок; после восстановления его может снова забрать тот же гонщик.
Пауза не уменьшает таймер. Новая гонка очищает таймеры и инвентари.

Начальный вес каждого предмета равен 1. Поддержка отстающего плавно смешивает
его с весом в таблице. Вероятность равна весу, делённому на сумму всех весов:

| Предмет | Вес при максимальной поддержке |
| --- | --- |
| Fanta | 1,40 |
| Mermaid Rum | 1,05 |
| Ice Rum | 1,20 |
| Stroh 80 | 1,15 |
| Lay's Crab | 0,90 |
| BFG 10K | 1,25 |

Все шесть предметов возможны на любом месте. Система не обещает отстающему
оружие или победу и не меняет веса в зависимости от бота/человека.
